comicgen

Give it a short story and get back a lettered comic book. An LLM writes the script, ComfyUI image models draw the cast and every panel, and code letters the balloons, all on your own PC.

Set it upSource on GitHub
  • NVIDIA graphics card with 12 GB (made on an RTX 3060 12 GB with 32 GB RAM)
  • Python 3.12 and ComfyUI (tested with 0.46.0)

comicgen is a Python program that drives your own ComfyUI. The model files aren't included: the table under Set it up links each one, about 32 GB in all.

What it can do

The same cast in every panel

Every character gets a turn-around sheet first, and every panel is drawn with those sheets as references. A change of clothes is drawn as an edit of the original, so the face carries over.

Lettering by code

The model draws each panel with balloons so the picture leaves room for them. SAM finds them, an edit removes them, and code letters the script's exact words back in.

You approve the cast

Every character, version and view in one place. Try a different look in plain words before any panel is drawn.

Change the story bible

Ask the LLM to change the cast, or edit it by hand. Only the pictures whose look changed are drawn again.

Edit the script

The script audit lists open problems. Fix them yourself or ask the LLM, panel by panel, then approve the script.

A reader for the finished comic

Read it page by page or panel by panel. It's written as a folder that opens offline in any browser.

Examples

Set it up

  1. Get the code

    Clone the repository and install its Python packages.

    git clone https://github.com/loopforge0/comicgen.git
cd comicgen
pip install -r requirements.txt

  2. Add the models to ComfyUI

    Download each file into the ComfyUI models folder shown, then start ComfyUI. It has to be listening on 127.0.0.1:8188.

    FilePut it inSize
    qwen_image_2.1_turbo_int8_convrot.safetensorsmodels/diffusion_models7.3 GB
    qwen_image_2.1_vae_bf16.safetensorsmodels/vae675.5 MB
    qwen3vl_8b_int8_convrot.safetensorsmodels/text_encoders9.4 GB
    moss_image_sft_int8_convrot.safetensorsmodels/diffusion_models5.4 GB
    flux2-vae_small.safetensorsmodels/vae249.5 MB
    qwen3.5_9b_w4a8_gptq.safetensorsmodels/text_encoders7.3 GB
    sam3.1_multiplex_fp16.safetensorsmodels/checkpoints1.7 GB

  3. Check that everything is in place

    This asks ComfyUI which nodes and model files it has, and lists anything missing with the folder it goes in.

    python -m comicgen check

  4. Make a comic

    Create a project from a story, then run, review and approve it in the tracker at http://127.0.0.1:8765. Four public-domain stories come with the code.

    python -m comicgen new elves --story stories/elves_and_the_shoemaker.txt --style teen_humour
python -m comicgen ui

  5. Or go straight through

    One command from story to finished pages, with no stops and no LLM call leaving your PC. The pages land in projects/elves/pages/.

    python -m comicgen new elves --story stories/elves_and_the_shoemaker.txt --auto-approve --local-only

Details

Models
Qwen3.5-9B (the LLM), Qwen Image 2.1 Turbo, MOSS Image, SAM 3.1 and Qwen3-VL 8B, all in ComfyUI
Made on
RTX 3060 12 GB, 32 GB RAM, with the LLM running locally for all four example comics
Other LLMs
LM Studio or any OpenAI-compatible server, or OpenRouter
Stories
plain text or a PDF with a text layer
Styles
teen_humour, silver_age, noir, modern_widescreen, romance_50s
