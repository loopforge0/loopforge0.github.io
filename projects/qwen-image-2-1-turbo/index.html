Run it yourself

The workflow on Civitai is ComfyUI's own Qwen-Image 2.1 template with two changes: the Turbo model file, and a SamplerCustom with Turbo's trained 8-step schedule in a ManualSigmas node. It needs ComfyUI 0.37.0 or newer.

Every test below also has the workflow that produced it, in ComfyUI's API format, with the exact inputs it loaded published beside it. Copy the inputs into ComfyUI/input and drag the workflow onto ComfyUI.

The text encoder and VAE are the same files as base 2.1, so if you already run 2.1 you only need the Turbo file. The base file is only needed for the comparison images.

At cfg 1 the negative prompt has no effect. In my test the output was pixel-identical with and without one.
