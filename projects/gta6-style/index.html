GTA VI art style from your photos

Turn your own photos, or just a description, into the look of the GTA VI key art with Qwen-Image 2.1 in ComfyUI. There is no LoRA and no reference image: the style comes entirely from the written prompt, so you can build that prompt right here, copy it, and use it in any Qwen-Image 2.1 workflow.

    Use it in ComfyUI

    With the prompt from this page

    1. Open any Qwen-Image 2.1 image workflow that uses TextEncodeQwenImage21.
    2. Paste the prompt into its prompt box, and set the canvas to the width and height shown above the prompt.
    3. For photos, connect them in the order of the people list: person 1 is image 1, person 2 is image 2. Text only needs no image.
    4. Use the base model at 40 steps (euler, simple, cfg 1). Turbo gave softer, anime-leaning faces in testing.

    Photos with busy backgrounds or dappled sunlight leak into the illustration. The workflows below first redo each photo on a plain studio background with an 8-step Turbo pass. You can do the same with any background-replacement edit before pasting the prompt.

    With the node pack

    The same choices as dropdowns, with the studio clean-up built in. In ComfyUI Manager choose Install via Git URL and paste https://github.com/loopforge0/comfyui-gta6-style, or git clone it into ComfyUI/custom_nodes/. Restart ComfyUI, then open a workflow. No extra Python packages.
