Notes

The boxes are drawn in the template's Create Bounding Boxes node. Each one is a text box (the exact words to spell and how they should look) or an object box (a description), and the MOSS-Image Layout Prompt node turns the caption and the boxes into the layout prompt the model was trained on. The Caption and Boxes tabs are exactly what those two nodes were given.

Box 2 is a character box: the man is described in words. The layout template takes no images.
